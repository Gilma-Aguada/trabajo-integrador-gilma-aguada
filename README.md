# ⚡ Zona Refri — Sistema de Gestión para Electrodomésticos

Bienvenido/a al repositorio oficial de **Zona Refri**, una solución backend diseñada para el servicio de reparación de electrodomésticos (pavas eléctricas, hornos, licuadoras, refrigeración y una gran variedad de equipos del hogar).

✨ **Proyecto desarrollado por Gilma Aguada.**

---

## 🚀 Tecnologías utilizadas

* **Java** (JDK compatible con Spring Boot)
* **Spring Boot**
* **Hibernate / JPA**
* **MySQL**
* **Postman** (colección incluida para testear la API)
* **Git & GitHub**

---

## 📂 Estructura del repositorio

* `src/` → Código fuente del backend (controladores, modelos, repositorios y servicios).
* `docs/` → Documentación técnica, diagramas entidad-relación (DER) y guías del proyecto.
* `ZonaRefri.postman_collection.json` → Colección de endpoints lista para importar y probar en Postman.
* `pom.xml` → Archivo de configuración de dependencias y plugins de Maven.
